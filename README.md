# Transactional Fraud Detection Analysis

## Project Overview

This project focuses on analyzing financial transactions and identifying fraudulent transaction patterns using Data Analytics and Machine Learning.

## Week 1: Data Preparation and Initial Exploration

### Work Completed

- Loaded the transaction dataset using Python and Pandas
- Performed initial data profiling using `info()` and `describe()`
- Checked missing values
- Checked duplicate records
- Analyzed fraudulent vs non-fraudulent transactions
- Analyzed fraud by transaction type
- Used SQLite and SQL queries for transaction analysis

### Key Findings

- Total Transactions: 6,362,620
- Fraudulent Transactions: 8,213
- Fraud Rate: Approximately 0.13%
- Fraud was concentrated in CASH_OUT and TRANSFER transactions
